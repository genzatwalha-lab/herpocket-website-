# Her Pocket Secret — Website

A responsive perfume storefront built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — page structure
- `styles.css` — responsive styling and bottle illustrations
- `script.js` — filters, cart drawer, localStorage cart, newsletter interaction
- `reference.jpg` — the image supplied as the design reference

## Run it
Open `index.html` in a browser.

For a local development server:
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000`.

## Customize
1. Edit the `products` array in `script.js`.
2. Change colors and spacing in `styles.css`.
3. Replace the WhatsApp number in `index.html` (`wa.me/256700000000`) with your business number.
4. Connect the checkout button to your preferred payment gateway.
